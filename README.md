
# AI Cloud Cost Detective

A Flask-based web application for analysing AWS cloud resource usage and costs and identifying potential cost optimization opportunities.

## Features

- Connects to AWS and retrieves cloud resource information
- Analyses AWS resource usage and cost data
- Provides cost summaries and resource utilization information
- Identifies underutilized resources and potential cost-saving opportunities
- Provides optimization recommendations through an AI-assisted component
- Web dashboard for viewing cloud cost and usage information

## Technologies

- Python
- Flask
- AWS
- Boto3
- HTML
- CSS
- JavaScript
- Docker

## AWS Services

The project works with AWS services including:

- Amazon EC2
- Amazon S3
- Amazon RDS
- Amazon EBS
- Elastic IP
- AWS Cost Explorer
- AWS STS
